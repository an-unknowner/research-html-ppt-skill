# 通用叙事与布局

## 按目的选叙事

| 用途 | 叙事链 |
|---|---|
| 科研/技术 | 问题 → 现状缺口 → 方法 → 证据 → 适用边界 → 下一步 |
| 项目进展 | 目标 → 进展与证据 → 偏差/风险 → 应对 → 后续里程碑 |
| 方案决策 | 决策问题 → 约束 → 可比方案 → 同维度证据 → 建议与代价 |
| 产品/业务 | 使用场景 → 用户问题 → 方案 → 价值证据 → 行动 |
| 教学/解释 | 直观现象 → 核心概念 → 机制/例子 → 应用 → 小结 |
| 结果对比 | 条件与基线 → 并列证据 → 差异 → 有条件结论 |

根据实际材料选取，不固定章节数量。每页回答一个主要问题，页间用问题、证据和判断承接。总结回应开场目标，后续行动回应已识别缺口。避免只按资料文件顺序堆页。

## 均匀布局不依赖具体模板

先按当前模板确定画布与安全区，再选择栅格。等价对象采用等宽/等高图位，同类页对齐标题、图片和图注。组内紧、组间松；文字或公式的多组内容在可用区域均匀分布，避免上密下空。

视觉平衡不等于所有页面对称：允许有明确主次的非等宽布局、全幅照片和无框图表，但同级元素须具有稳定的间距和对齐关系。空白应服务层级与阅读节奏；不增加无意义文字来填满空间，不靠缩小字号处理拥挤。

图像保留比例与证据完整性；比较对象对齐视觉尺度与条件。图注尽量采用“对象＋短结论”，解释放备注或附录；业务/教学场景同样避免把长段文字栅格化成图片。

## 内容与模板分离

内容记录保存页面 ID、对象 ID、主要问题、证据、结论、条件与备注。模板配置保存画布、字体、颜色、布局和组件。二者通过语义版式角色关联，不能把颜色类名或页码当成对象身份。

同一对象在目录、页眉、图例、图注和总结使用标准名称；共享事实改一次后同步全部引用。局部实验或业务场景使用独立条件 ID，避免误改其他场景。

HTML 可以采用集中数据渲染，PPTX 可以维护内容清单并映射至原生对象。统一内容源是原则，具体字段名和技术实现不是所有模板的强制要求。
