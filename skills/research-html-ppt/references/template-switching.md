# 模板选择与切换

## 路由与配置

按顺序选择：本次明确指定 → 编辑稿自身模板 → 会话中已确认模板 → 按主题新建。内置 `research-blue` 仅在选择原科研蓝白风格时启用。新模板可以是本地 HTML、PPTX、PDF、截图或明确文字风格，不需要先注册或安装。

建立随稿保存的简短模板配置，内容包括：模板 ID/名称、来源路径、输出格式、画布比例、字体层级、语义颜色、页边距、间距层级、页眉/页脚规则、版式角色映射、图片/公式规则及允许的例外。HTML 可用 JSON，PPTX 可用生成源中的配置或简短制作记录；无需强制某种文件名。配置跟随交付源文件，不仅存在聊天记录中。

不指定输出格式时，编辑任务保持原格式；新建时依本次请求和上下文判断，只在无法合理推断且会影响交付时询问。PPTX 模板并不意味着禁止输出 HTML，跨格式转换时必须说明可编辑性、字体和动画等实际差异。

## 适配外部模板

1. 读取结构并渲染代表页面：封面、普通内容、对照、图表和结束；提取的是可复用规则，不是示例业务内容。完整套用前检查全部源版式。
2. 提取当前模板的尺寸、栅格、字体、配色、图片语言与重复元素。不要把内置模板的深蓝/红色、固定圆角、面板、24 px 间距或 16:9 画布作为通用限制。
3. 建立语义角色映射：封面、目录/转场、单图、比较、流程、结果、计划、结束、附录。允许同一角色有多个版式，也允许省略不需要的角色。
4. 复用原生结构：HTML 使用其共享样式；PPTX 使用主题、母版、占位符。仅图片/PDF 参考需要重建结构，不声称恢复了原生母版或可编辑图表。
5. 找不到合适版式时，按目标模板的视觉语言新建兼容变体或拆页；不能偷偷回退到原蓝白模板。证据和必要条件优先保留。

## 中途切换流程

- 记录当前内容清单与稳定 ID，保留原稿。确认目标模板来源与切换范围；“整套换模板”默认全稿，只有明确局部要求才局部处理。
- 先做角色映射：源页 ID → 内容职责 → 目标版式 → 需要重新排布的图文。章节与数据顺序保持，除非用户要求重组叙事。
- 应用目标模板的画布、字体、语义色、边距和组件；根据比例重新布局，不把整页非等比拉伸。保留图像原始比例、坐标与图例。
- 统一修改图表颜色、图内字号和图注位置；方法/对象的颜色映射在全稿一致。如必须改色，更新所有关联图例，不能只替换页面背景。
- 内容模型不随换模板改写。方法名称、数值、单位、结论、条件与备注保留；长内容通过重排、简化非关键措辞或拆页适配，不能删证据换取整齐。
- 优先验证代表页再扩展全稿；交付前检查每一页，排除旧模板残留、裁切、溢出和跨页不同步。切换结果以渲染与内容清单复核为准。

## 边界情形

- 模板文件缺失：先查已提供路径与工作区；无法取得时请求补充，不假装已按参考复刻。仍可先组织内容清单。
- 多个候选模板未指定：已有明确上下文则沿用，否则询问选择；不要混合不相容的视觉系统。
- 字体不可用：选择支持所需字符的近似字体并说明替代，重新检查换行。
- 用户只要求修改内容：保留当前模板；用户要求换风格：不擅自改科学结论。

## 使用示例

- “使用这个 skill，参考提供的 PPTX 制作项目进展汇报，输出 HTML。”
- “保留全部内容，把这套蓝白汇报切换到附件中的极简模板。”
- “不使用内置模板，为产品方案建立新的视觉风格并输出 PPTX。”
- “沿用现有模板，只更新实验结果，确保标题和图例全局同步。”

这些是触发制作流程的自然语言指令，不是已实现的命令行接口或运行时换肤 API。
