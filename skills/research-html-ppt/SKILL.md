# 可切换模板的 PPT 制作

本 skill 分为“通用制作规则”和“当前模板配置”。更换模板只改变视觉系统和版式映射，不丢失内容、对象关系与科学证据。

## 触发与执行入口

- 用户要求 HTML PPT、网页幻灯片、浏览器演示或 HTML slides，即进入演示制作流程；不能因为输出是 HTML 而按普通网站流程处理。继续制作、局部修改、换模板也适用。
- 开始制作前读取本文件及当前路径所需的引用，简短说明正在使用本 skill；先确定输出格式、模板、字体层级表与强调色，再写页面。不要只读取模板后跳过正文约束。
- 交付前逐项检查本文件的验收项，说明实际验证范围与未完成项；没有执行浏览器渲染检查时，不得声称已验证视觉效果。
- 自动发现依赖宿主加载 skill 的描述与安装位置，正文不能保证自身被触发。未触发时显式使用 `$research-html-ppt`；检查安装副本是否更新、`allow_implicit_invocation` 是否为 true，以及会话可用 skill 列表是否包含本 skill。仓库修改不会自动同步个人安装。

## 全稿字体层级与自动重点强调

- 先定义语义层级：页标题、模块标题、正文一级、正文二级、图注与注释。全稿同层级统一字体族、字号、字重、行高与字距，按内容角色归类，不能按所在卡片或页号另定字号。
- HTML 使用共享 CSS 变量和语义类；PPTX 使用主题、母版和段落级别。外部模板也要映射到同一层级表。空间不足优先精简、拆页或换版式，不允许单页缩小同级正文。确需调整字号时统一调整全稿该层级并复查溢出。
- 数学符号与代码可使用专用字体；封面标题可定义独立角色，但不能把普通正文逐页命名成例外以绕过一致性。
- 主动判断每段叙述的重点：优先核心技术机制或细节，其次区别性特点、关键数据指标（保留数值、单位、比较基准及必要限定词）。无法判断时强调原文中描述特点的形容词或短语；没有合适词时不强行着色，不添加未经证实的评价。
- 每段通常选 1–2 处短语，避免整句整段染色。全稿叙述强调只使用一个共享强调色，依当前模板选取并检查背景对比度；不改变图表系列、警告等已有语义色。
- HTML 用 `.text-emphasis { color: var(--color-emphasis); font: inherit; }` 标记重点，PPTX 使用同一主题强调色的文本片段；强调不改变字号或破坏同级字体。保留公式结构、否定词和适用条件，避免截断强调造成误读。
- 验收时跨页按语义层级比较实际计算字体样式（包括被嵌套元素或内联样式覆盖的文本），检查所有重点的实际颜色是否一致，并人工检查重点选择是否忠于原意。打印与导出后复查可读性，不能只检查 CSS 声明。

## 模板选择与切换

先读 [模板选择与切换](references/template-switching.md)，确定输出格式、模板来源和适用范围。优先采用用户本次指定的模板；修改现有演示时沿用其模板；继续制作时沿用已确认的模板。没有参考时依据主题建立新视觉方案，不自动套用本次科研蓝白模板。

- **内置科研蓝白**：用户明确选择本次风格时，读 [内置模板规范](references/design-and-story.md)，复制 [空白模板](assets/blank-template.html)。
- **外部模板**：读取用户给定的 HTML、PPTX、PDF 或截图参考，提取视觉参数与版式角色，不把其中的示例文字、姓名、机构或数据当成新稿事实。
- **无模板新建**：按受众、主题和输出形式建立适用的共享视觉参数与版式库；可以使用留白、图片主导或其他风格，无需沿用蓝白、固定面板或 1280 × 720。
- **中途切换**：遵照映射流程迁移全稿，保留源稿与内容记录，检查所有页面；不能仅换颜色就宣称完成模板切换。

这里的“切换”是制作流程能力，不代表 HTML 中已添加运行时换肤按钮。只有用户要求交互换肤时才实现该控件。

## 必须维持的四项约束

1. **跨页一致**：只从共享版式选择结构。画布、标题基线、栏宽、图位、图注和颜色由同一组样式变量控制；同类页不能逐页微调成不同风格。先压缩表达、拆页或换版式，再考虑字号调整。
2. **全局语义一致**：同一对象使用稳定 ID，统一名称、符号、标题、单位、颜色、状态与结论。编辑局部时，先判断它修改的是共享事实还是局部实验条件；共享事实修改源数据后同步所有引用，局部条件用带工况 ID 的独立记录，不能盲目全局替换字符串。
3. **图像优先**：用曲线、示意、流程、对照图表达关系。图注只写“对象＋结论”的短语，通常一行，必要时两短行。禁止把长解释塞进图片；前提、推导和讨论放备注或附录。真实数据图保持坐标轴、单位、图例和不确定性定义。
4. **布局均匀**：同级模块等宽或等高，横纵间距统一，图像与图注对齐；各内容组在可用区域内均衡分布，避免上密下空、左右失衡或局部拥挤。按信息层级保留组间留白，不为填满页面拉伸图片、增添文字或把所有间隔机械等分。具体尺寸服从当前模板；均匀布局原则适用于所有模板。

## 制作与修改

- 先依据受众建立叙事链，按 [通用叙事与布局](references/general-authoring.md) 选择合适结构，不机械复刻某次参考汇报的章节或页数。
- 列出每页要回答的问题、支撑证据、结论、叙事角色、对象 ID 与版式，再排版。一页服务一个主要判断。
- 内容与视觉分离：为对象、共享结论和页面分配稳定 ID，维护唯一内容源与引用关系。内置 HTML 可用 `deck-data/entities/claims`；外部 HTML 沿用兼容的数据结构；PPTX 可用内容清单和原生占位符映射。不强制重写外部模板，也不要求 PPTX 具有 DOM 或 JSON。目录、页眉、图注和总结按同源记录同步。
- 对名称、指标、状态、结论的修改，扫描目录、总览、页眉、正文、图中文字、图例、图注、总结、附录、备注；对图片内文字必须重绘或替换，不能只改外部图注。
- HTML 样式调整改共享变量或版式类；PPTX 优先修改主题、母版和共享版式；仅在内容确实特殊时增加具名变体，并检验所有使用该类的页面。不要叠加多段同名 CSS、页码选择器和 `!important` 补丁。
- 保留用户提供的科学内容与适用条件。不以概念插画替代真实实验，不凭视觉美化捏造改善率，不把区间收窄等同于真实参数必然准确。
- 空白模板的文本、图像路径、结论和数据保持空字符串；框线、编号与布局保留。没有证据时留空或明确待验证，不能编造示例结论。

## 交付前检查

- 全稿缩略检查叙事节奏；HTML 逐页检查实际浏览器渲染，PPTX/PDF 检查导出渲染，不以尺寸或结构检查代替视觉检查。
- 检查布局均匀：同级块尺寸与间距一致，左右视觉重量平衡，上下留白协调；跨页比较同类版式。
- 比对当前模板具有的重复元素（页眉、图位、图注等），不强制新增蓝色总结条或面板。检查文字溢出、图片变形、坐标裁切、公式可读性。
- 针对一次共享实体改名，验证目录/页眉/总结等引用同步；针对一次工况修改，验证其他工况没有被误改。测试副本不能污染交付稿。
- 页码从实际页序自动生成，主稿与附录分组计数；增删重排后复核目录和跳转。图片没有加载成功不能视为完成。
- HTML 检查翻页、缩放、打印和资源完整性；单文件嵌入资源，离线使用不依赖 CDN。PPTX 检查母版、图片、字体、公式、可编辑性及导出效果；不要仅把整页截图塞进 PPTX 并称为可编辑模板。输出格式遵从用户要求。
- 切换后比对内容清单：对象名、结论、数值、单位、图例、附录、备注与顺序无遗漏；所有页面服从目标模板，未转换页面必须说明。
- 说明完成内容和未验证项。安装到个人 skills 目录后可在不同项目调用；项目内副本与全局安装相互独立，更新时明确目标版本。
